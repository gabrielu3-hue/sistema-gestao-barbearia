# Sistema de Gestão de Barbearia

Sistema de gestão de barbearia desenvolvido em Java, utilizando Programação Orientada a Objetos (POO), Git, GitHub e Desenvolvimento Orientado a Testes (TDD).

## Objetivo do projeto

O objetivo é desenvolver um sistema para auxiliar no gerenciamento de uma barbearia, organizando clientes, barbeiros, serviços, agendamentos, atendimentos e pagamentos.

## Funcionalidades

- Cadastro, consulta, atualização e exclusão de clientes.
- Cadastro e gerenciamento de barbeiros.
- Cadastro e gerenciamento de serviços.
- Gerenciamento de agendamentos.
- Registro e gerenciamento de atendimentos realizados.
- Gerenciamento de pagamentos.

## Tecnologias utilizadas

- Java 17
- Programação Orientada a Objetos (POO)
- Maven
- JUnit 5
- Git e GitHub
- TDD (RED, GREEN e REFACTOR)

## Estrutura do projeto

- `src/main/java`: código-fonte das classes do sistema.
- `src/test/java`: testes automatizados com JUnit 5.
- `evidencias`: capturas de tela que comprovam a execução dos testes.

## Como compilar o projeto

Com o Java e o Maven instalados, execute no terminal:

```bash
mvn clean compile
```

## Como executar os testes

Para executar todos os testes automatizados:

```bash
mvn clean test
```

## Resultado dos testes

O projeto possui 184 testes automatizados, todos aprovados na última execução, sem falhas ou erros.

Resultado: BUILD SUCCESS.

As evidências estão disponíveis na pasta `evidencias`.
